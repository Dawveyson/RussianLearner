如何配置 / 修改公告？

本页内容来自仓库里的 docs/config.json。要发布新公告或更新版本号，编辑该文件后提交到 GitHub 即可（App 会自动拉取）。config.json 结构：

{
  "latestVersionCode": 10,
  "latestVersionName": "1.1.0",
  "apkUrl": "https://github.com/.../app-release.apk",
  "announcements": [
    {
      "id": "唯一ID",
      "title": "标题",
      "date": "2026-10-06",
      "level": "info | warn | danger | ok",
      "body": "公告正文，支持换行"
    }
  ]
}

提示：latestVersionCode 需大于 App 当前的 versionCode 才会提示更新；apkUrl 指向可下载的 APK。
